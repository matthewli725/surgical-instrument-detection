# TrayGuard Docs

This directory is organized so background, experiments, and project planning can
be updated independently as the capstone evolves.

## Structure

- `background/`: project framing, problem definition, and design context
- `experiments/`: experiment writeups grouped by technical theme
- `planning/`: weekly updates, remaining-quarter tasks, and presentation-facing
  planning artifacts
